# OCP Trajectory Visualization

Comprehensive tools for visualizing Optimal Control Problem (OCP) solutions from both single JSON trajectories and NPZ datasets.

## 📁 Files Overview

| File | Purpose | Input Format | Use Case |
|------|---------|--------------|----------|
| `visualize_trajectories.py` | Visualize single OCP solutions | JSON files | After solving individual problems |
| `visualize_dataset.py` | Browse and analyze dataset | NPZ files | Exploring generated datasets |
| `simple_visualize.py` | Quick visualization example | JSON files | Getting started |
| `simple_dataset_viz.py` | Dataset exploration example | NPZ files | Dataset analysis template |

## 🚀 Quick Start

### For Single Trajectories (JSON)
```bash
# Interactive view with both plots
python scripts/visualize_trajectories.py ocp_solution.json

# Save for presentation
python scripts/visualize_trajectories.py ocp_solution.json \
    --save-static paper_figure.png --save-anim presentation.gif
```

### For Dataset Exploration (NPZ)
```bash
# Explore random sample (both static and animation windows)
python scripts/visualize_dataset.py --animate

# View specific sample
python scripts/visualize_dataset.py --index 42 --animate

# Dataset quality check (grid overview)
python scripts/visualize_dataset.py --overview --num-runs 16
```

## visualize_trajectories.py - Complete Reference

### Purpose
Visualize single OCP solution trajectories from JSON files generated by the C++ solver.

### Command-Line Arguments

```
python scripts/visualize_trajectories.py <json_file> [OPTIONS]

Positional:
  json_file              Path to trajectory JSON file

Options:
  --obstacles FILE       Path to obstacles JSON (default: src/cpp/robot/environment/obstacles.json)
  --static              Show static plot only
  --animate             Show animation only
  --save-static FILE    Save static plot to FILE
  --save-anim FILE      Save animation as GIF to FILE
  --fps FPS             Animation frames per second (default: 10)
  --no-display          Only save files, don't display windows
```

### Usage Examples

#### Basic Interactive Viewing

```bash
# Default: shows both static and animation windows
python scripts/visualize_trajectories.py ocp_solution.json

# With custom obstacles file
python scripts/visualize_trajectories.py ocp_solution.json \
    --obstacles my_obstacles.json

# Show only static plot (no animation)
python scripts/visualize_trajectories.py ocp_solution.json --static

# Show only animation (no static plot)
python scripts/visualize_trajectories.py ocp_solution.json --animate
```

#### Saving Outputs

```bash
# Save static plot only
python scripts/visualize_trajectories.py ocp_solution.json \
    --save-static trajectory_plot.png

# Save animation only  
python scripts/visualize_trajectories.py ocp_solution.json \
    --save-anim trajectory_animation.gif

# Save both (files saved, windows still displayed)
python scripts/visualize_trajectories.py ocp_solution.json \
    --save-static plot.png --save-anim anim.gif

# Save both without displaying (headless mode - for servers/scripts)
python scripts/visualize_trajectories.py ocp_solution.json \
    --save-static plot.png --save-anim anim.gif --no-display

# High-quality animation (higher FPS)
python scripts/visualize_trajectories.py ocp_solution.json \
    --save-anim smooth_anim.gif --fps 20
```

#### Integrated With C++ Workflow

```bash
# Run C++ solver then immediately visualize
./build/Release/control_learning && \
    python scripts/visualize_trajectories.py ocp_solution.json --animate

# Run solver with custom initial/target, then visualize
./build/Release/control_learning \
    --init 1.0 2.0 0.5 --target 5.0 3.0 1.57 \
    --output my_trajectory.json && \
    python scripts/visualize_trajectories.py my_trajectory.json
```

## visualize_dataset.py - Complete Reference

### Purpose
Browse, analyze, and visualize trajectories from NPZ dataset files generated by the dataset generator.

### Command-Line Arguments

```
python scripts/visualize_dataset.py [OPTIONS]

Dataset Selection:
  --dataset PATH         Path to .npz file (default: data/dataset.npz)
  --index N             Visualize specific sample N
  --num-runs N          Visualize N random samples (default: 1)
  --seed SEED           Random seed for reproducibility

Display Modes:
  --overview            Show grid overview of multiple samples
  --animate             Show both static and animated plots simultaneously

Output Options:
  --save PATH           Save static plot to PATH
  --save-anim PATH      Save animation as GIF to PATH  
  --save-dir DIR        Save multiple outputs to DIR
  --fps FPS             Animation frames per second (default: 10)
  --no-display          Only save files, don't display windows
```

### Usage Examples - Basic

```bash
# View a random sample (static plot only)
python scripts/visualize_dataset.py

# View random sample with both static and animation (windows open together)
python scripts/visualize_dataset.py --animate

# View specific sample
python scripts/visualize_dataset.py --index 42

# View specific sample with both windows
python scripts/visualize_dataset.py --index 42 --animate

# Use different dataset
python scripts/visualize_dataset.py --dataset data/dataset1.npz --index 10
```

## Common Workflows

### 1. Dataset Generation and Exploration

```bash
# Step 1: Generate dataset
python scripts/dataset_generation/generator.py

# Step 2: Quality check (grid overview)
python scripts/visualize_dataset.py --overview --num-runs 16

# Step 3: Deep dive on interesting samples  
python scripts/visualize_dataset.py --index 42 --animate
python scripts/visualize_dataset.py --index 128 --animate
```

### 2. Creating Presentation Materials

```bash
# High-quality static figures for paper
python scripts/visualize_dataset.py --index 50 \
    --save paper_figures/optimal_trajectory.png --no-display

# Smooth animation for presentation
python scripts/visualize_dataset.py --index 50 \
    --save-anim presentation/demo_animation.gif --fps 20 --no-display

# Overview figure
python scripts/visualize_dataset.py --overview --num-runs 12 \
    --save-dir paper_figures/ --no-display --seed 42
```

### 3. Batch Analysis

```bash
# Export first 100 samples
for i in {0..99}; do
    python scripts/visualize_dataset.py --index $i \
        --save analysis/sample_$(printf "%04d" $i).png --no-display
done
```

## Troubleshooting

### Windows Not Appearing

**Problem**: matplotlib windows don't show up (especially in WSL)

**Solutions**:
```bash
# Option 1: Use --no-display and view saved files
python scripts/visualize_dataset.py --index 42 \
    --save plot.png --save-anim anim.gif --no-display

# Option 2 (WSL): Run from Windows PowerShell
cd \\wsl$\Ubuntu\home\user\mpc_dl\control_learning
python scripts/visualize_dataset.py --index 42 --animate

# Option 3: Set up X11 server (VcXsrv on Windows)
export DISPLAY=:0
python scripts/visualize_dataset.py --index 42
```

### Animation Window Appears After Closing Static Plot

**Fixed!** With `--animate` flag, both windows now open simultaneously (static is non-blocking).

### Script "Hangs" or Appears Frozen

**This is normal when**:
- Saving GIF animations (can take 30-90 seconds)
- matplotlib window is open (waiting for you to close it)

**Solutions**:
```bash
# Use --no-display to avoid window blocking
python scripts/visualize_dataset.py --save-anim out.gif --no-display

# Or just close the matplotlib window when done viewing
```

### FileNotFoundError: dataset.npz not found

**Solution**: Specify correct path
```bash
python scripts/visualize_dataset.py --dataset data/my_dataset.npz
```

### ValueError: Index out of range

**Solution**: Check dataset size first
```python
import numpy as np
data = np.load('data/dataset.npz')
print(f"Dataset has {len(data['inputs'])} samples")
# Use index 0 to len-1
```

### Different n_intervals Between Datasets

The visualizer automatically handles different interval sizes (50, 100, etc.) by reading from metadata.

### Low Quality Animations

**Solution**: Increase FPS and resolution
```bash
python scripts/visualize_dataset.py --index 42 \
    --save-anim high_quality.gif --fps 20 --no-display
```

### Memory Issues with Large Datasets

```python
# Don't load entire dataset at once
viz = DatasetVisualizer('large_dataset.npz')
# Visualize one sample at a time
for idx in range(0, 1000, 100):
    viz.plot_trajectory(idx, save_path=f'sample_{idx}.png', show=False)
```

## Performance Tips

### Faster Animation Generation

```bash
# Lower FPS for faster generation
python scripts/visualize_dataset.py --save-anim quick.gif --fps 5 --no-display

# Higher FPS for smoother (but slower) animation  
python scripts/visualize_dataset.py --save-anim smooth.gif --fps 30 --no-display
```

### Batch Processing Optimization

```bash
# Use xargs for parallel processing
seq 0 99 | xargs -P 8 -I {} python scripts/visualize_dataset.py \
    --index {} --save batch/sample_{}.png --no-display

# Or GNU parallel
parallel -j 8 python scripts/visualize_dataset.py --index {} \
    --save batch/sample_{}.png --no-display ::: {0..99}
```

## File Formats and Sizes

### Typical Output Sizes

| Output Type | Typical Size | Notes |
|-------------|--------------|-------|
| Static PNG (default) | 400-600 KB | High quality, 300 DPI |
| Overview PNG (9 samples) | 300-400 KB | Grid layout |
| Animation GIF (10 FPS) | 500 KB - 1.5 MB | 50-100 frames |
| Animation GIF (20 FPS) | 1-3 MB | Smoother, larger file |

### Reducing File Sizes

```bash
# Lower resolution static plots (not recommended)
# Edit script to change dpi=300 to dpi=150

# More efficient: Use lower FPS for animations
python scripts/visualize_dataset.py --save-anim small.gif --fps 8

# Or use video format instead (requires additional tools)
# Convert GIF to MP4 for much smaller size:
ffmpeg -i animation.gif -movflags faststart animation.mp4
```
